# AI & School System

_2026-08-07_

AI empowers people to do a lot of things not possible before.

It enables an ordinary person to do things only an expert can do. And most
importantly, AI empowers people to learn.

I used to get stuck when facing a programming problem because I have nobody to
ask.  But not any more. I can ask an AI and it does not only explains it to me
but also in a way that I can understand.  It is an extremely patient teacher
with infinite resources and available all the time.  It is your 24/7 personal tutor.

AI enables self-paced learning at scale.  Anymore who is eager to learn can
learn as fast as he can.  No need for enrollment. No more fixed cirriculum. No
more grading system.  No more geographical boundary. And teachers are always
available.

The school system will need to adapt in order to remain relevant.
